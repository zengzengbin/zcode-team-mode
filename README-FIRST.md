# zcode-team-mode 分享包 — 三步上手

这是 **ZCode 小队模式**技能的一键安装包：装好后，你在聊天里输入口令，ZCode 就会按"主 Agent 拆解任务 → 四个专职小队成员（探索/执行/评审/专家，各自固定模型和思考强度）分工干活"的方式工作。

## 三步走

1. **解压**本压缩包（记住解压出来的文件夹位置）。
2. **把包丢给你的 ZCode**：在 ZCode 对话里告诉它包的绝对路径，并说一句——

   > 请按照包内 INSTALL-AI.md 的指引，在这台机器上安装并验证 zcode-team-mode 技能。

   你的 ZCode 会引导你完成 4 个角色的**模型与思考强度初始化设置**（你可选用推荐预设，也可指定自己已有的任意模型渠道），并自动完成文件部署、hook 注册与自检，全程向你汇报。
3. **重启 ZCode（或新开一个聊天）**，然后单独一行输入：

   ```text
   $zcode-team-mode
   ```

   看到"👾 已开启小队模式"即成功。之后正常派活即可，任务完成不会自动退出；想退出就发"退出小队模式"。

## 前提

- 机器上装有 **Node.js**（hook 依赖它，正常使用 ZCode 的机器基本都有）；
- ZCode 中已配置至少一个可用模型渠道（不论是官方渠道、中转 API 还是自定义代理）。安装时 AI 会询问并帮您将 4 个小队角色绑定到你最顺手的模型上。

## 角色分工与推荐配置参考

| 角色 | 职责定位 | 推荐选型 | 推荐思考强度 |
|---|---|---|---|
| `team-explorer` | 只读定位、代码库搜寻、调用链分析 | 轻量快速模型（如各类 Flash / Mini / Haiku） | `high` |
| `team-executor` | 代码实现、修改、测试验证与交付 | 主力编程代码模型（如 DeepSeek-V3/V4、Sonnet、GPT-4o 等） | `max` 或 `high` |
| `team-reviewer` | 独立只读代码评审，严苛查验实质缺陷 | 强推理分析、长上下文模型（如 Kimi-K2.8、Opus、Sonnet 等） | `max` 或 `high` |
| `team-expert-advisor` | 架构决策、疑难诊断、受权复杂任务 | 旗舰推理模型（如 Kimi-K3、o1、R1 等） | `xhigh` 或 `max` |

> **提示**：安装初始化只做一次设置。后续如需调整，可随时在 ZCode 设置界面中修改，或直接编辑 `~/.zcode/agents/team-*.md`。

## 常用口令

| 口令（单独一行发送） | 作用 |
|---|---|
| `$zcode-team-mode` 或 `开启小队模式` | 启用（仅首轮出现一次标记行，防重复） |
| `退出小队模式` | 关闭（仅首轮出现一次关闭标记） |
| `查看小队状态` | 查询当前聊天状态 |

## 进阶技巧：派发上下文分档

子 Agent 无法直接共享父会话全部历史，技能内内置了三档任务说明模板：
- **轻量档**：目标、范围、验收依据、写权限（常规定位与修改）；
- **中等档**：轻量全部 + 「已定决策」逐条摘要（涉及近期架构决议时）；
- **完整档**：中等全部 + 关键证据文件路径（复杂调查，让成员自己去读文件，避免大段原文丢失失真）。

## 出问题了？

把情况直接丢给你的 ZCode：让它看 INSTALL-AI.md 的"故障排查"章节；它也可以随时按第六节帮你**干净卸载**。安装改动都有备份（`config.json.bak-team-mode`），可一键还原。
